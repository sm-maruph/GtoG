# CBC Enterprise Operations Portal

React/Vite demonstration portal for Commercial Bank of Ceylon PLC, Bangladesh Operation.

Implemented modules:

- Insurance Management Tracker
- Vehicle Booking System
- Stationery Inventory Management
- Utility Tracker
- Paper Usage Tracker
- Super Admin Portal

The project includes granular `SELF`, `DEPT`, `BRANCH`, and `GLOBAL` permissions, organization/user/role management, welcome dialogs, dark enterprise navigation, and global audit logging.

## Run locally

```bash
npm install
npm run dev
```
